# 当前技术路径:热源驱动的 PCB 红外温度重建与预报(中文说明)

**文档角色:**本文用中文说明本项目当前采用的技术路径,即"热源优先"的重建与预报管线,
与 `docs/dynamic_inverse_zh.md`(旧动态反演对照路径的中文文档)相对应。英文的已实现
方法记录见 `docs/plans/stage2_reconstruction.md` 与 `docs/plans/stage3_forecasting.md`。
`CLAUDE.md` 仍是唯一权威;本文与其冲突时,以 `CLAUDE.md` 为准。本文描述的是 2026-09-01
已完成并提交的 case10 负载盲基准。

## 1. 为什么是这条路

红外相机假设所有表面发射率为 0.95。哑光表面读数可信;金属外壳(芯片盖、连接器排)在
红外下近似镜子,读数混入房间反射,不可信。case10(树莓派 4B 裸板)约 44.7% 的板面属于
这类区域,最深处距任何可信数据 20 mm。

早期两条路都失败过:

- 从时间序列反演发射率:噪声太大,效果差;
- 电导率优先:得不到热源的数量与位置,难以推广到其他板,而且**从不构造温度,只给参数
  估计**。

当前路径刻意绕开这两点:**不估计任何发射率**(0.95 就是可信像素上真值的定义,不是拟合
值),并把电导率**除掉**而不是测出来。管线是:

1. 识别低发射率区块(不可信 footprint);
2. 用导数的方向识别热源的数量与位置(可信板与区块分开做);
3. 用薄板传导方法重建每帧完整温度图;
4. 在重建结果上建立物理预报模型,可从任意时刻向前预测。

约束:只做前向预测;红外图像是默认输入(case10 不用任何 CPU 负载记录或系统日志);
负载停止后的冷却段不用,只重建通电段(帧 0-239,0-1498 s)。

三个交付物:通电段每一帧的重建图、从任一指定帧向前的整段预报、`hotspots.csv`。

## 2. 物理模型与单位约定

PCB 是薄板:热量穿过板厚几乎瞬时,唯一慢的过程是沿板面横向扩散。每个像素在每个时刻
都满足同一收支方程:

```
升温速率 (K/s)
    = 横向扩散速率 (px^2/s) × 局部曲率 (K/px^2)
    - 冷却速率 (1/s) × 高于环境的温升 (K)
    + 加热速率 (K/s)
```

三项分别是:邻居横向传来的热、漏给空气的热、原地产生的热。

**关键一步:全式除以单位面积热容。**它让三个量都变得可以直接从温度影像测得(升温速率
是时间导数,曲率是空间二阶差分);代价是绝对尺度被销毁——把热容、电导、空气散热、功率
同乘一个常数,所有温度轨迹完全不变。因此:

- **永远不输出、不声称 W、W/K、W/(m*K)、W/m^2**;所有量都是速率(K/s、px^2/s、1/s);
- 热点只能**排名与比较**,不能说"某元件占整机功耗的百分之几"——热容随板面位置变化,
  连热点之间的比值都不是功率比。

命名规则:全项目使用平实词语,不用希腊字母(横向扩散速率、冷却速率、加热速率、响应
时间、扩散距离、温升、热点、模式库),每个报告量必须带单位。

## 4. 三个速率的估计(Phase 1,tdp/thermal/sources.py)

每个速率来自一种**不同的观测量**。

**负载停止帧**(`find_load_drop`):板均升温速率在负载停止处出现最大的单帧下跌——case10
在帧 239/240 之间从 +0.009 跳到 -0.089 K/s。之后的数据全部不用。

**冷却速率**(`fit_cooling_rate`):恒定功率驱动下,板均温升按指数趋近平衡:

```
温升(t) = 平衡温升 + (起始温升 - 平衡温升) × exp(-冷却速率 × t)
```

只用通电段的 240 个板均值做非线性最小二乘。两个盲测检验:拟合的平衡温升 26.63 K 对实测
26.70 K;拟合的起始温升 13.70 K 对从未参与拟合的实测空闲电平 13.90 K。结果
**0.00685 /s,响应时间 146 s**。

**加热速率**(`measure_heating_rate`):方程重排,把热源单独放在一边:

```
加热速率 = 升温速率 + 冷却速率 × 温升 - 横向扩散速率 × 曲率
```

逐像素计算。生产用 rise 估计:负载恒定,所以每像素一个常数,每帧是它的一次观测,取平均
即最小二乘解(10 帧与 70 帧的热点排名只差 1-3 px)。副估计 onset 只用最初几帧——升温项
在那里主导,几乎不依赖假定的冷却速率——两个估计的热点位置差 1-3 px,互为印证。三条守卫
各防一种实测过的翻车:

- **lid 边缘 3 px 内关闭曲率项**:raw 场在金属盖边缘是一个台阶(发射率伪影,不是温度),
  该处曲率 0.558 对干净板 0.092 K/px^2,是 6 倍;不关会沿每条边缘注入 0.35 K/s 纯伪影
  (真信号的三分之一),并在边缘"制造"热点——不加守卫时十大热点有七个正好压在 lid 边上。
- **用原始场,不修正发射率**:lid 让读数差一个静态乘性因子(约 2.3 倍),它只压低幅值,
  不移动、不虚构峰值,所以盖下的热点仍能定位,标记为下界。
- **曲率用镜像边界**:热量不从画面侧面流失(板从板面散热,不从画面边缘)。

**横向扩散速率**(`fit_spread_rate`):盯住最强热点看它随时间变宽。一块热在导热薄板里
其平方宽度线性增长:

```
平方宽度 = 固有宽度^2 + 2 × 横向扩散速率 × 时间
```

对每个时间窗拟合"高斯鼓包 + 倾斜背景"(裸二阶矩依赖基线放在哪,曾让 6 个候选中 4 个的
表观宽度随时间缩小——物理上不可能)。case10 实测:平方宽度从 6.5 s 的 34.4 px^2 只爬到
34.5 s 的 38.7 px^2,热几乎不横向走;得 0.3-0.6 px^2/s、扩散距离 5-9 mm,**分辨能力
不足**。生产因此**选用** 2.0 px^2/s(= 9.27 mm):重建对该速率五倍变化只移动 6%,对已知
板回填留出孔在超过 5.5 mm 后触底——刻意把数据分辨最差的速率放在管线最不敏感的位置。

## 5. 热源定位(Phase 1)

**可信板上**:在加热速率图里找热点。必须用时间导数,不能用单帧的空间二阶导——后者在
raw 场上找到的是 lid 台阶,在修复场上又"找不到"被修复置零的源。

**不可信区块:边缘一致性判据**(区块内部读数不可信,永不使用)。块内产生的热必须从边界
流出,所以绕块一周温度都应向外下降;被动金属块泡在板梯度里,一侧进热一侧出热,净热近零。
case10 的判定:

- **SoC 区块**,269 mm^2,位于 (26.1, 32.7) mm:24 个扇区中 22 个 100% 外向,板温向外从
  37.5 降到 29.5 K——**唯一的热源区块**;
- **970 mm^2 连接器排**:22% 外向,板温向外反而从 18 升到 26 K——无源(业主肉眼确认);
- 可信板上另有一个热点 (17.9, 10.3) mm。

判据是**初筛不是判决**:区块 4(175 mm^2,(9.9, 42.9) mm)边缘测试说无源(33% 外向,
-0.20 K),拟合热源却说它全场最强(+0.344 K/s);case17 实测真值 29.9 K、全场第二热——
拟合赢了。结果写入交付物 `hotspots.csv`。

## 6. Stage 2:整帧温度重建(tdp/thermal/reconstruct.py)

**每帧独立求解,不需要初始条件。**板从未冷过(帧 0 已高于环境 11.3 K),把升温速率挪到
等式另一边:

```
横向扩散速率 × 曲率 - 冷却速率 × 温升 + [加热速率 - 升温速率] = 0
```

方括号内称为该块的**热源速率**(K/s)。这不是近似,什么都没丢——瞬态整体挪进了源项。
区块内"加热"与"升温"分不开,而恰好只有它们的差进入方程,能被拟合。

**强度定标:留出环带。**所有 footprint 合集周围 8 px 一圈可信像素暂时从求解中藏起,每块一个源幅度,选成
"最好地复现环带的实测温度"。环带必须留出:把环带自己的测量热源喂回去,同时又用它当
边界,是一个什么都不约束的恒等式。每块预计算一个影响场后全序列线性,240 帧 约 5 s CPU。

**形状分两种。**无源块直接用环带解。确认为热源的 lid(仅 SoC)用**广域热源薄板解**:
footprint 加 1 px 过渡边作为一个板域,域内一个非负的均匀热源,幅度保住环带拟合的块均值;
不粘贴曲线、不平滑、不打平核心——平台和它向实测板的过渡由同一传导-冷却方程生成。
case10 帧 200:SoC 最深四分之一 41.66 K,无源解只有 29.45 K——平滑没有把热源抹掉。

**裁判:case17。**同一块板喷哑光黑漆,case10 必须猜的地方在 case17 有真值。施加 case10
的遮罩、重建其遮住的 39.5%:

| 重建方法 | 平均误差 | 系统偏差 |
|---|---|---|
| 边缘插值,无热源(旧法) | 3.68 K | **-2.10 K**,每帧偏冷 |
| 热源驱动,块内均匀源 | 2.63 K | **+0.01 K** |
| 中心加权源(临时) | 2.37 K | +0.37 K |
| 广域热源薄板解(最终) | **2.29 K** | +0.37 K |

消除系统性偏冷是本阶段的核心——偏冷正是"缺源"的物理签名:无源解不可能在内部超过边界。
消融:把所有块都中心加权反而 2.98 K(连接器排真是分布式的);有源块留成均匀只损失
0.03 K,无源块误加权损失数 K,所以只对高置信的热源块加权。

**残余与不确定度,如实报告。**剩余 2.29 K 分解为错误的电平与错误的内部模式:就算把每块
源拟合到 case17 的真值(单数字的极限),仍剩 1.57 K,其中模式 1.56 K、电平 0.20 K——
**再加源参数救不了模式**。逐块电平误差达 ±4.4 K 且互相抵消(SoC 块 -4.4 K 冷、区块 1
+4.5 K 热,板均值近零)——**必须看逐块数字,不能只看板均值**。每帧附逐像素**模型区间**
(留出环带误差按距离放大 + 两个解的分歧),它不是置信区间;重建像素在后续预报中权重被
压低,永远得不到观测权重 1。

## 7. Stage 3a:固定模式库与闭合解(tdp/thermal/patterns.py、forecast.py)

约一万六千个像素并不是一万六千个独立热自由度——传导把相邻像素强耦合。这正是空洞能被
物理填出的原因,也说明固定模式库够用:

- 候选:板拉普拉斯最慢的 64 个自然模式 + 三种热源几何(整板背景、SoC footprint、可信板
  热点)在 4 个试探扩散率(0.5、1、2、4 px^2/s)下的平衡响应;
- 主元 QR 正交化,76 个候选留 72 个独立模式;建库不读任何温度帧;
- 热源响应不可省:纯平滑模式装不下紧凑热点;
- 细网格校验门限 0.10 K,当前最差 < 1e-10 K;固定库对档案的投影 0.596 K 是**截断诊断,
  不是预报分数**。

模式坐标下方程线性,用**矩阵指数**在任意正时间步上精确推进(等宽步长复用同一过渡矩阵),
平衡态一次线性求解。**任意帧起步**:指定起始帧在时刻零精确等于重建场;基外细节作为显式
的未解析残差按其自身粗糙度衰减,从不被伪装成拟合热源。

## 8. Stage 3b:冻结划分与被拒绝的模型

划分先于一切模型选择,连续帧块 + 3 帧保护带(相邻帧约 6 s 一拍近乎重复,**永不随机切帧**):

| 角色 | 帧块(含端点) |
|---|---|
| 训练 | 0-44, 51-92, 147-188 |
| 验证 | 99-140 |
| 留出测试 | 195-239 |

自足导出 `stage3_training_export.npz` 可离机复现拟合。

直觉方案——三路非负平滑热源史——被测过并**拒绝**:留出测试加权平均绝对误差 2.145 K,
输给持续性基准 0.270 K。三路源撑不起 72 个模式;用大而无约束的带符号修正去救它,只会让
修正顶替物理。保留为失败消融(`source_history_fit.npz`),不用于生产。

## 9. 生产模型:向平衡场弛豫(tdp/thermal/train_forecast.py)

后期帧显示 SoC 区域趋近与其邻域几乎相同的局部电平(业主指出的性质),生产预报直接用它:

```
初始偏差 = 起始场 - 平衡全温度场
已解析偏差(t) = 稳定板过渡 × 已解析初始偏差
未解析偏差(t) = 未解析初始偏差 × 冷却衰减
预报(t) = 平衡场 + 已解析偏差 + 未解析偏差
```

平衡全温度场 = 最后一个训练块(帧 147-188,即 922-1178 s)的均值,不含任何验证或测试帧。
四条性质:时刻零精确;一切偏差都衰减,收敛到平衡场;源形模式保住 SoC 平台;基外细节被
声明并平滑消散。验证扫过扩散倍率 0.8/1.0/1.2、冷却倍率 0.9/1.0/1.1、残差衰减倍率
0.5/1.0/2.0;验证差小于 0.01 K(低于文件 0.1 K 分辨率)视为不可区分,带内保留独立测量值:
横向扩散速率 2.0 px^2/s、冷却速率 0.006851 /s。

**留出结果(加权平均绝对误差,前向窗口:给定起始帧,只计其后的帧):**

| 模型 | 留出测试 |
|---|---:|
| 生产:向平衡场弛豫 | **0.191 K**(验证 0.185 K) |
| 持续性基准(温度保持不变) | 0.270 K |
| 常数热源驱动 | 1.774 K |
| 三路非负平滑热源史 | 2.145 K |
| 无热源 | 15.336 K |

帧 0 起步、对全部 240 个实测通电帧为 0.422 K。SoC 区块 0.155 K——但这是**与 Stage 2 估计
的一致性**,不是盖下真值的精度。

## 11. 边界:我们不主张什么

- **无瓦特、无功率占比**:相对单位是物理(尺度被除热容销毁),不是风格。
- **lid 下的电平只有环带的精度**:逐块电平误差可能 ±4.4 K 并在板均值里抵消;重建像素在
  预报中永远是降权估计,不是隐藏真值。
- **扩散距离分辨差**(5-9 mm):case10 稳态径向剖面从中心到 42 mm 平坦到 10% 以内,近
  等温;任何报告几毫米"扩散长度"的拟合,先对照无模型的径向剖面再信。
- **case10 调参到此为止**:不再在其留出测试上继续调。新的精度工作需要新证据——喷漆真值
  板,或带修正中心温度传感器的硬件(可经可选接口 `InteriorTemperatureAnchor` 注入;
  case10 基准不使用它)。
- **未来固定负载模型已批准、未实现**:输入契约为"起始温度场 + 0 到 1 的固定负载 + 未来
  时刻",最少需要 5 个负载档 × 各 3 次独立会话(15 次通电记录);详见
